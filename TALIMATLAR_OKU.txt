GITHUB ACTIONS ILE OTOMATIK APK OLUSTURMA REHBERI (SIFIR KURULUM)

Bu paket bilgisayariniza hicbir program (Node.js, Android Studio vb.) kurmadan, dogrudan GitHub uzerinden APK elde etmeniz icin hazirlanmistir.

ADIMLAR:
1. GitHub'da yeni bir public veya private "Repository" olusturun.
2. Indirdiginiz bu ZIP dosyasinin icindeki TUM KLASOR VE DOSYALARI (.github klasoru dahil olmak uzere) GitHub reponuza yukleyin.
   Dosya yapisi tam olarak su sekilde gorunmelidir:
   - .github/workflows/build.yml
   - www/index.html
   - www/ekg_verileri.json
   - package.json
   - capacitor.config.json

3. Dosyalari yukleyip "Commit" ettiginiz anda GitHub Actions otomatik olarak calismaya baslayacaktir.
4. GitHub sayfanizin ust kismindaki "Actions" sekmesine tiklayin.
5. Orada "Android APK Derle (Capacitor)" isimli islemin calistigini (sari daire) goreceksiniz.
6. Islem tamamlandiginda (yesil tik ciktiginda) ustune tiklayin.
7. Sayfanin en altindaki "Artifacts" bolumunde "EKG-Pro-APK" isimli linki goreceksiniz.
8. Bu linke tiklayarak APK dosyasini bilgisayariniza/telefonunuza indirebilirsiniz!

Not: S23 Ultra telefonunuza bu APK'yi dogrudan atip yukleyebilirsiniz.
